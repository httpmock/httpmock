### Can I start multiple mock servers in one Rust test function?
Yes. `httpmock` keeps the servers in a pool with a default limit of 25 and blocks `MockServer::start` once
the pool is exhausted until another test releases a server. You can raise the limit with the
`HTTPMOCK_MAX_SERVERS` environment variable. The environment variables the library reads are listed in the
[API reference](https://docs.rs/httpmock/latest/httpmock/).

### In which order are mocks evaluated?
When a request matches several mocks, the one that was created first wins. Mocks limited with
[`Then::up_to_n_times`](https://docs.rs/httpmock/latest/httpmock/struct.Then.html#method.up_to_n_times) are
skipped once they have been served that many times, so the next matching mock takes over.

### How do I upgrade to a new release?
The [upgrading page](/miscellaneous/upgrading/) lists the breaking changes of each release as a checklist, with
the replacement APIs. The complete list of changes is in the
[changelog on GitHub](https://github.com/httpmock/httpmock/blob/master/CHANGELOG.md).

### How does Proxy Mode work?

In proxy mode the mock server sits between your system under test and the real service as a
man-in-the-middle proxy. For plain HTTP that just means the request passes through the mock server, which can
read, record and forward it. For HTTPS the client would normally open a CONNECT tunnel and encrypt the
traffic end to end, so the mock server has to terminate TLS itself: it presents the client a certificate for
the destination host, decrypts the request, opens its own TLS connection to the real service, and re-encrypts
the response on the way back.

The certificates for the destination hosts are generated on the fly and signed by the mock server's CA
certificate, either the built-in one or one you provide. Your client has to trust that CA for the setup to
work, which is what makes the interception consensual. The [HTTPS page](/server/https/) shows how to
configure the certificate, and the [recording page](/record-and-playback/recording/) how to use proxy mode to
record traffic.
